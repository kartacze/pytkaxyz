Welcome to the blog! This post is written in **MDX**, which means you can mix
Markdown with JSX components.

## Why MDX

MDX lets you use interactive components directly inside your Markdown. Here's a
live counter rendered with an Astro component:

import Counter from '../../components/Counter.astro'

<Counter />

## Code blocks

You can also drop in code samples:

```ts
const greeting: string = 'hello world'
console.log(greeting)
```
